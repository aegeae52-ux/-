# وقتي – منظّم وقت الطالب

تطبيق ويب (PWA) بيساعد الطالب ينظّم مهامه ويذاكر بتركيز: مؤقت بومودورو، مراجعات بالتكرار المتباعد، حاسبة، وتلخيص الدروس بالذكاء الاصطناعي (نص / PDF / صورة) مع تحميل الملخص PDF.

## الملفات
- `index.html` : التطبيق كله (HTML + CSS + JS)
- `manifest.json` : بيانات التطبيق عشان يتثبّت
- `sw.js` : بيخلي التطبيق يشتغل بدون إنترنت
- `icon-192.png` و `icon-512.png` و `icon-maskable-512.png` : الأيقونات
- `.nojekyll` : عشان GitHub Pages يعرض الملفات زي ما هي

## 1) الرفع على GitHub
1. اعمل حساب على github.com، واضغط **New repository** وسمّيه `waqti` وخليه **Public**.
2. اضغط **uploading an existing file** وارفع كل ملفات المجلد (بما فيها `.nojekyll`)، واضغط **Commit changes**.
3. روح **Settings ← Pages**، وفي **Source** اختار **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. استنى دقيقة، وهيظهرلك الرابط: `https://اسمك.github.io/waqti/`

## 2) تحويله لتطبيق
- **أندرويد (الأسهل):** افتح الرابط في Chrome ← القائمة ⋮ ← **تثبيت التطبيق**.
- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **ملف APK حقيقي:** ادخل على pwabuilder.com، الصق رابط الموقع، واضغط **Package for stores ← Android**، ونزّل الملف.
